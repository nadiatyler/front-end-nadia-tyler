# Mulheres em Tech 🚀

Este é um projeto front-end desenvolvido em **React** com **Vite**, focado em dar visibilidade a personalidades femininas que marcaram a história da tecnologia.

## 🛠️ Tecnologias Utilizadas
* **React** - Biblioteca JavaScript para construção da interface.
* **Vite** - Build tool para um desenvolvimento rápido.
* **Vercel** - Plataforma utilizada para o deploy e hospedagem.

## 🔗 Links
* **Site ao vivo:** [Acesse aqui](https://front-end-nadia-tyler.vercel.app/)

## 🏗️ Como executar o projeto localmente
1. Clone o repositório:
   `git clone https://github.com/nadiatyler/front-end-nadia-tyler.git`
2. Instale as dependências:
   `npm install`
3. Inicie o servidor de desenvolvimento:
   `npm run dev`
